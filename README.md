# Truck-Multi-Drone Cooperative Delivery Reproducibility Repository

This repository contains benchmark data, computational results, and implementation files for truck-multi-drone cooperative delivery experiments.

## Contents

- `data/`: computational result files, run-level metrics, and Pareto-front objective values used for the main tables and figures.
- `code/`: implementation of the improved NSGA-II, baseline algorithms, and aligned Gurobi small-scale benchmark.
- `docs/`: descriptions of the Solomon-based instance preprocessing rules and data-file consistency checks.

The repository supports verification of the computational results reported in the manuscript.
